# Memory Game

Игра на поиск пар: игрок открывает карточки и запоминает их расположение, цель - найти все совпадения за наименьшее число ходов.

## Правила Игры

1. Игра начинается автоматически при первой загрузке и каждой перезагрузке страницы. Все 16 карточек перемешаны и скрыты от игрока, счётчик ходов **(Moves)** равен 0, найденных пар **(Successfully)** — 0 из 8. Игрок сразу может открывать карточки.
2. Игрок открывает одну карточку, затем другую. **Один ход — открытие двух разных доступных карточек**, независимо от того, совпали они или нет.
3. Если изображения совпали, обе карточки остаются открытыми до конца игры. Счётчик найденных пар **(Successfully)** увеличивается на 1.
4. Если изображения различаются, обе карточки остаются видимыми примерно секунду, затем закрываются. Пока игрок рассматривает несовпавшую пару, открыть другие карточки нельзя.
5. Когда найдены все 8 пар, игра завершена. Автоматически откройте модальное окно с сообщением о победе, итоговым количеством ходов **(Moves)** и кнопками «Новая игра» **(New Game)** и «Закрыть» **(Close)**.
6. В хедере расположены кнопки «Новая игра» **(New Game)** и «Таблица лидеров» **(Leaderboard)**. «Новая игра» **(New Game)** начинает игру заново: карточки перемешиваются и закрываются, счётчики обнуляются. «Таблица лидеров» **(Leaderboard)** временно не работает.
